# Mohammad Ahmad Khan — Portfolio

A responsive personal portfolio presenting Mohammad Ahmad Khan's work and learning in digital marketing, social media growth, market research and product development.

## Live website

https://ahmadconnects27.github.io/PORTFOLIO/

## Built with

- HTML5
- CSS3 (custom properties, responsive layouts and motion effects)
- Vanilla JavaScript

## Sections

- Professional introduction and selected growth metrics
- About profile
- Marketing Manager experience at Jaksons Pvt Ltd
- Social Media Growth & Engagement Campaign
- Air Pillow — Innovative Product Development Project
- Digital marketing, research, analytics and soft skills
- Tools and platforms
- Education, certifications and workshops
- Contact details and professional links

## Run locally

Open `index.html` in a modern browser. No build tools or package installation are required.

## Deployment

This is a static website suitable for GitHub Pages. Configure GitHub Pages to publish from the `main` branch.
